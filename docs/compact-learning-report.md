# 学习页一屏布局与明亮配色

2026-11-06。本轮仅修改本地 WordTest 界面，没有提交、推送或部署，线上 https://eju-tango.ai.studio/ 仍是此前版本。

## 改动

- 单元选择和返回合为一行，去除重复单元标题、学习页页脚及多余留白。
- 单词和重听按钮并排；释义、日语例句、中文译文及用法提示完整保留。例句按钮仍为整行、至少 56px 高，其他学习控件至少 44px。
- 移除“理解声音里的意思”“在句子里理解”“教学例句 · 自编”“✓ 已保存到本机”。保留简短的听懂状态、修改标记、保存中和失败提示。
- 完成页压缩记录列表，保留全部记录、下一单元和重新听一遍。
- 参考 [EJU 官方网站](https://www.jasso.go.jp/ryugaku/eju/index.html) 的白底、蓝青和浅色分区，采用更明亮的浅蓝背景、青色装饰与淡金提示。颜色是本项目适配值，不声称与官网色值完全一致。

## 验证范围

Chromium 和 WebKit 中逐项操作全部 50 个词条，覆盖未作答、答案、重听，以及五个单元完成页。以下视口均无水平或垂直溢出，操作按钮在屏幕内：

| 视口（CSS 像素） | 结果 |
|---|---|
| 390 × 844 | 通过 |
| 375 × 667 | 通过 |
| 320 × 740 | 通过 |
| 1280 × 800 | 通过 |

没有通过隐藏溢出来裁切内容。320 × 400 短视窗和测试注入的双倍答案字号可自然滚动，例句、下一项和完成后的重听操作可达。此测试不等于真实系统字体缩放验收。

独立代码审查检查了界面 diff、保存保护和测试，指出播放按钮的小字对比度不足；已调整主色为 #08778e、悬停背景为 #e6f4f7，并新增浏览器计算检查。播放按钮正常/悬停文字对比度约 4.77:1 / 4.62:1。审查未发现新增存储或播放器逻辑问题；修正后独立复核确认对比度与短视窗测试反馈均已关闭。

初轮布局测试发现完成页在 375 × 667 高出 33px；已减少记录行间距，复测通过。相关失败日志保留，未掩盖失败结果。

## 实际限制

- 未进行真实 iPhone/Safari、浏览器工具栏伸缩、VoiceOver 或系统字号设置的实机验收；WebKit 是自动化模拟环境。
- 极短屏幕、横屏或文字放大允许自然滚动，优先保证完整内容和操作可访问。首页单元列表本轮未要求一屏显示。
- 未改变音频文件，未重新进行听感审核；未增加云端保存、PIN 或复习调度。
- 尚未将本次修改发布到线上，因此线上现有版本不会自动获得本轮布局。
