## 选词依据与边界

[JASSO 日语考试大纲](https://www.jasso.go.jp/ryugaku/eju/examinee/syllabus/japanese.html)考查读解、聴解、聴読解和记述，涉及信息理解、关系理解和运用。这里按这些任务选词，不把 EJU 描述成单独考词义的考试，也不承诺背完即可提高固定分数。

本批出现统计采用 2016 年第 2 回、2017 年第 1 回、第 2 回的 **3 份公开日本语题册**，主要覆盖可公开的读解、聴読解图表/题干和记述题。公开版本有缺题，不能代表所有历年题目。2018-1 扫描页和所下载的听力脚本文字映射不可靠，未纳入频次统计，不能称为已统计听力高频词。

出处、PDF SHA-256、页码和排除项见 `content/evidence/jasso-public-sample.json`；本机 PDF/提取文本见 `artifacts/jasso-corpus/`。采用去除注音与空白后的指定表记字面匹配，并核对语境；没有做完整词形还原或全量 OCR。主要看出现过的场次，次数只留作审计（同题选项重复会抬高次数）。0 命中不等于没考过。

已排除“比較的”对“比較”的误计，以及书目中的“調査”；“分析力”是同义复合词命中，单独注明。“調査”作为理解对象、结果和分析的基础概念保留，属于用途补充项，不标为样本高频。全部例句为本批自编，未复制试题段落。

## 学习顺序与分类

单元 1：一方 → 対象 → 方法 → 比較 → 資料 → 条件 → 影響 → 締め切り → 理由 → つまり。

单元 2：結果 → 調査 → 割合 → 特徴 → 変化 → 分析 → 重要 → 増加 → 傾向 → 必ずしも〜ない。

先理解关系与要求，再理解数据和限定判断；先备词出现在分析、趋势等词之前。校园事务、研究、逻辑和图表用途穿插，避免连续堆放大量近义词。分类与顺序分开存储，今后可按 `categoryIds` 筛选，不需要修改稳定条目 ID。

这属于依据学习研究制定的编辑策略，不是经过该学生实验验证的唯一最优顺序。依据包括[检索练习研究](https://doi.org/10.1126/science.1152408)、[分散练习综述](https://escholarship.org/uc/item/3rr6q10c)及[词汇语义相关性与间隔研究](https://doi.org/10.1017/S0272263118000219)。后者不能简单概括成“同类词永远不能一起学”。当前两个静态单元并不代表已实现每日新词配额或间隔复习日期算法。

## 音频结构决策

| 方案 | 本批判断 |
|---|---|
| 整单元一个长文件 | 修改一句需重生成整段；独立重听和重排依赖切片时间，不采用 |
| 每词把词语和例句合成一个文件 | 必须跳到固定时间才能只听例句，不采用 |
| 每项两个独立文件 + 清单 | 采用；适合先听词语、再揭示答案和播放例句，可独立重听、排序、缓存 |

句型的 listenText 用完整短句，不朗读“〜”或不完整语法片段。默认标准日语 `ja-JP-NanamiNeural`、正常语速，不叠加情绪风格。已通过账号声音列表确认可用；尚不能因此认定声音自然度或所有汉字读音正确。

Azure 直接输出 `audio-24khz-96kbitrate-mono-mp3`，本批保存原始返回的 MP3，不进行二次有损编码。暂不增加 WAV 母版请求或同一文本多音色全量生成；如后续需要剪辑/混音，再选择 PCM 母版。

```
content/pilots/eju-20-v1.json               # 文本、分类、顺序、来源命中
content/reviews/eju-20-text.json           # 独立文本审核，绑定整个 items 哈希
artifacts/audio/eju-20-v1/
  run-ledger.json                         # 累计请求与预算（失败也保留）
  candidate-manifest.json                 # 条目/角色 → 请求 → 文件
  cache/<request-sha256>.json             # 文本、声音、语速、格式、时间及文件摘要
  audio/<file-sha256>.mp3                 # 相同内容复用；不可变文件地址
  rejected/                              # 技术拒绝的响应与诊断资料（如有）
```

请求哈希包含文本、声音、语速、SSML 和格式；单元清单调整无需重新生成。内容 ID 独立于音频哈希，分析沿用原来的 `eju-03-004-a`，其新增例句不会覆盖旧包。

## 运行与预算

```sh
# 默认预览，不需要密钥、不合成
npm run content:audio

# 本批实际完成后重新运行只复用缓存；未命中的请求仍受账本约束
npm run content:audio -- --generate --env-file ~/.zshrc --max-calls 41 --max-chars 14254
```

`--env-file` 使用 dotenv 文本解析，只读取 AZURE_ENDPOINT / AZURE_KEY，不 source、不执行 shell 文件。仅支持直接赋值；若变量来自命令替换或其他脚本，先在调用进程导出变量。真实值不写入仓库、前端或候选内容；不要使用 VITE_ 前缀。

首次预览为 40 个不同请求、565 个朗读 Unicode 字符。工具将序列化 SSML 长度乘二作为保守预算单位（13,930），它既不是准确计费字符数，也不是金额。首次合成因本地检查误判损失 1 次请求/324 单位，已记录原因并将总上限修订为 41 次/14,254 单位，计数未重置。

真实费用需以账号区域、价格层级、免费余额和 Azure 账单为准；不能凭字符少就称为免费。[官方计费说明](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/text-to-speech)和[价格页](https://azure.microsoft.com/en-us/pricing/details/speech/)。

失败不自动重试；相同请求最多累计 3 次。修改已有账本的上限会被命令拒绝，必须检查剩余工作并记录预算修订。中断遗留 `.lock` 时先确认原进程结束，不要并发启动或随手删除锁。
