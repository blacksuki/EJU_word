# 单元选择与正式使用界面更新

日期：2026-11-06。项目：WordTest。仅本地开发与构建，没有部署、收费 API 调用或新依赖。

## 已完成

- 首页直接展示五个单元的有序列表，保留既定学习顺序、目标及各单元进度；学生可以从任意单元进入。
- 学习页新增原生单元选择器。切换停止旧音频、独立恢复各单元记录，刷新留在当前单元；保存中和反馈保存失败时禁用切换及返回。
- 移除人工听审、开发验证、音频制作、词频统计等内部展示信息，保留词义、搭配和必要的用法区别。未改变已审核的源数据或音频。
- 有原五项记录或读取异常时才显示历史入口；旧链接与记录仍可使用。
- 参考 [JASSO EJU 官方页面](https://www.jasso.go.jp/ryugaku/eju/index.html) 实际页面，采用白底、深蓝青色、浅灰分区及少量青色/金色点缀。保留自身名称，没有使用 JASSO 标识。
- 单元选择器高度52px，例句按钮至少56px。新增页面说明与浏览器主题色。

## 独立审查及修复

独立 reviewer 只读检查了本轮快照、源码、测试与截图，未参与实现。发现一项原有 P2：顶部品牌链接可绕过保存保护，在保存失败后离开并丢弃尚未确认的反馈。

先用实际浏览器复现保存中/失败后点击品牌会离开，再将学习中的品牌改为静态标识；返回首页统一走已有受保护的“返回单元列表”按钮。两种状态在 Chromium 和 WebKit 共4项回归通过。未再安排第二轮审查，以失败测试→修复→完整回归核验。

截图检查另发现 WebKit 原生 select 忽略 min-height、只有23px高度。先以触摸尺寸断言复现，再控制外观并显式设置52px；保留原生选择交互。320/390/1280宽度均通过布局检查，最终截图已实际查看。

## 限制与实施判断

- 本次“正式使用”指移除内部界面信息并生成可用构建包；不是宣称历史完整V1规划全部实现。FSRS、每日配额、云端、PIN、分类筛选及公网部署均未在本轮实现。
- 没有iPhone真机验证；WebKit手机尺寸模拟和真实桌面浏览器验证不能替代实机Safari验收。
- 保留审核文件中的内部信息作为证据；仅清理学生界面。代价是今后扩词时仍需检查新备注是否夹带内部说明。
- 应用内返回统一受保护；不新增浏览器关闭/强制刷新确认。用户强制离开仍可能丢失尚未保存成功的反馈，已成功保存记录不受此次改动影响。
- 沿用用户指定目录，无可用Git流程，因此使用原文件快照和日志记录；没有代为接受Xcode协议、初始化Git、提交或部署。

刷新原本地页面即可使用新界面；服务未运行时执行 npm run dev。后续工作应由用户选择，未提前增加功能。
