# 线上网站功能验收

对象：https://eju-tango.ai.studio/

时间：2026-11-06，约18:16—18:20（Asia/Tokyo）。结论：**实际线上核心学习流程通过，本次检查未发现阻断使用的功能故障。** 本轮没有修改应用代码、重新部署或操作个人浏览器记录。

## 验证方式

浏览器直接访问上述HTTPS域名，没有启动本地网页服务。使用独立Chromium/WebKit会话及测试专用持久化目录，保留Google平台实际注入并生效的Service Worker。网页、词库和音频全部从线上读取。

原有浏览器用例复制到临时审查目录，只将测试地址改为线上域名，并为网络访问适当增加等待时间。原有5个依赖page.route拦截请求的故障用例（两个浏览器共10项）本轮不执行，以免平台Service Worker改变拦截路径后产生误判；另增加真实断网与恢复用例，在两个浏览器各执行一次。没有拦截或替换正常学习流程的线上内容。

## 结果

浏览器验收共40项：**39通过，1跳过，0失败、0重试后通过**。

## 平台附加行为

Google在HTML中追加Service Worker和WebSocket包装脚本。已读取实际线上脚本，并在受其控制的浏览器中完成验收。

脚本主要代理Gemini请求；正常学习抽查中没有观察到Gemini/Azure请求或非GET请求。两种浏览器的独立正常流程抽查均无页面异常、console error或HTTP 4xx/5xx响应。故障测试中人为断网及存储异常不计作网站自然故障。

这是正常学习流程抽查结果，不是对平台全部功能的安全审计或未来调用费用保证。当前页面播放的是预生成MP3，不依赖现场生成语音。

## 实际限制

- 学习记录仍保存在当前域名下的当前浏览器；不是云同步，也不会自动继承本机5173端口或Studio预览域名的记录。
- 已验证断网错误处理与恢复，未承诺整站完全离线可用。
- 未验证真实iPhone硬件、所有Safari版本、跨设备同步、长时间运行或未来重新部署后的缓存升级。
- 本轮针对线上版本进行验收，不重新执行本地单测/构建来冒充线上检查。上轮开发配置问题不因当前网站可用而自动视为已修复。
