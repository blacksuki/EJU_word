## 独立审核与修复

独立代理 `/root/pilot_independent_review` 检查文本、来源、预算、缓存和凭据边界，并复核以下修复：

1. PDF.js 提取时转移了原字节缓冲区，导致最初来源摘要误为空内容摘要；从实际保存 PDF 重算，并逐一独立复核。
2. 候选音频最初仅记录不可逆请求哈希；已保存实际文本、声音、语速、格式、提供者和生成时间，新增失败测试后修复。
3. 真实生成入口必须阻止未审核文本；现先检查状态及审核摘要，再读取凭据、联网。修改例句会使审核失效。

真实生成首段被本地技术检查拒绝。用本地无 Xing 时长头的合法 CBR MP3 复现出检查器把时长估算提示视为损坏的问题，红测后修复；仅放行这一明确提示，其它解码警告仍拒绝。随后 4 段小样及余下 36 段均通过。首段原始响应在当时未保存，故不能对那一段的具体信号状态做追溯断言；现技术拒绝的响应会保存到 rejected 目录。

另修复生成报告未累加本次预算单位的问题（原始 Azure 生成日志中的 budgetUnits=0 是旧报告错误，不能理解为免费或未调用）。累计账本始终正确，红测及最终 52 项单测通过；后续缓存预览显示 0 是确实没有新生成需求。
