## 来源与审核边界

继续使用已核对的 JASSO 2016-2、2017-1、2017-2 三份公开题册。命中可定位至 PDF 页码及提取文本位置；活用词按逐项记录的表记/词干匹配并人工语境排除，不声称全量词形还原。场次统计不等于完整历年考频，也没有补做听力脚本统计。原方案中的調査仍是用途补充项，不因本次扩充伪造命中。

新增材料已排除研究机构及书目、研究科/研究生与研究目标词的混计、名词申し込み对动词申し込む的混计、非数量用法必要以上等。独立审核另外发现并排除了情報的参考文章标题与現在的出版社说明。

新增 30 项读音、义项、例句和翻译均通过独立文本审核；前 20 项复用先前审核，并验证逐对象完全一致。审核记录见 `content/reviews/eju-50-text.json`。真实音频听审不以文本检查代替。

## 生成和复用

沿用 ja-JP-NanamiNeural、正常语速、词语/完整表达与例句各一 MP3。新目录 `artifacts/audio/eju-50-v1/` 导入了旧 40 个经哈希和解码验证的缓存，不复制旧账本；新增请求使用独立账本，最多 60 次和 21,008 个保守预算单位，失败不会自动追加重试。预算单位不是准确 Azure 计费字符或金额。

```sh
# 默认保留旧 20 项预览
npm run content:audio

# 50 项预览，不产生合成请求
npm run content:audio:50

# 如需恢复同一批次，复用缓存并沿用原上限
npm run content:audio:50 -- --generate --env-file ~/.zshrc --max-calls 60 --max-chars 21008
```

程序中的 --pilot-size 只能为 20 或 50；--limit-items 只用于小样，不能超过所选批次。真实合成仍先检查整个批次的文本审核摘要，再读取凭据。新内容目录和音频目录不在生产 public 包中；当前学习网页仍是原 5 项，不会破坏已保存的学习记录。
