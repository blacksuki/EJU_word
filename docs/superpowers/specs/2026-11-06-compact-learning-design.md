# 学习页一屏布局与明亮配色

用户要求：学习内容在一屏显示，移除冗余教学及保存成功文案，参考 EJU 官网明亮配色。本次为既有界面的明确调整，复用播放器、记录与导航逻辑。

实现：单元选择和返回合为一行；单词与重听按钮并排；释义、用法提示、例句保持完整；移除指定四项文案，保留简短的听懂状态、修改标记及失败提示；学习中不显示页脚。完成页压缩记录列表，不删除记录。白底、蓝青主色、浅蓝分区与淡金提示参考 https://www.jasso.go.jp/ryugaku/eju/index.html ，颜色数值是本项目的适配选择。

验收：Chromium / WebKit 中检查所有 50 项的未作答、答案、重听及五个完成页；目标 390×844、375×667、320×740 和桌面 1280×800，无水平或垂直溢出，例句按钮至少 56px，导航及词语播放至少 44px。不通过隐藏溢出裁切内容；极短视窗、横屏和字体放大保留自然滚动以保证可访问。运行保存、刷新、重复点击及失败保护回归、类型检查和构建。未改音频、词库、记录算法；不部署。
