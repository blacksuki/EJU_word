# 学习单元列表与正式界面

依据：用户已测试可用，要求选择学习单元、去掉人工听审等内部提示、采用 EJU 官网相近配色。

首页以五个单元的有序列表为主体，保留现有单元顺序、目标与进度；压缩原大幅宣传区。学习页使用原生下拉列表切换单元，适配手机原生选择器。切换时停止旧音频，独立记录和刷新恢复沿用现有实现；保存中或反馈未确认保存时禁用切换。

采用白底、深蓝青标题/按钮、浅灰分区、少量青色与金色装饰，参考 https://www.jasso.go.jp/ryugaku/eju/index.html （2026-11-06 已浏览页面）。保持自身名称，不使用 JASSO 标识。保留大号例句按钮、错误提示和本机保存说明，移除人工听审、开发验证等学生无需处理的信息。审核资料不删除。旧五项记录仅在存在记录或读取异常时显示首页入口，直接链接仍可用。

实现选择：复用现有单元、状态和播放器；不引入路由库或自制弹窗选择器。原生 select 能直接调用手机平台选择控件。本轮为本地正式使用界面整理，不部署，也不实现云端、复习调度或分类筛选。
