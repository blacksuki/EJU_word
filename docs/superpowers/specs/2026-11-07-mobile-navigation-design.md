# 手机优先学习导航

用户指定：手机左滑前一个、右滑下一个，底部回到学习单元；明确允许未标记右滑跳过，以后补学。

采用正文卡片和底部按钮的布局：顶部单元选择、进度；卡片保留完整词义、例句、大号音频按钮；下方前一个/下一项和回到学习单元。手机学习页去掉独立品牌栏，避免新增底部操作挤出一屏。保留点击按钮，手势不是唯一操作途径。

导航与评分分离：前后切换原子保存游标，不产生评分。回到旧词可重听和修正评分。未标记词通过缺少有效评分判断，不新增重复数据。单元末尾有遗漏则显示待补学列表并提供补学入口，将恢复游标保存为首个遗漏词；全部标记才写完成游标 null。重听已经完成的单元仍为只读，前后滑动不改原记录。

手势只在 <=600px 卡片正文中处理单指触摸：>=64px 横移，水平位移至少为纵移1.5倍，持续<=900ms。忽略按钮起点、24px浏览器边缘、纵向滚动、多指和取消事件；不阻止垂直滚动/缩放。边界不跨单元。保存中、评分失败待重试不可绕过保护；位置保存失败保留原卡片并提示重试。换词停止旧音频，不自动播放新音频。

继续验证 390×844、375×667、320×740、1280×800，一屏布局不裁切正文；极短屏/大字号允许滚动。真实iPhone尚需实机验收。本轮不部署。
